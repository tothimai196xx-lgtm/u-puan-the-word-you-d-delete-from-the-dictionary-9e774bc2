The word I would delete from the dictionary forever: **queue**.

Five letters, four of them silent. Strike it from the dictionary and the
language loses nothing — the letter "q" was doing all the work anyway.
The joke is the word itself: a word that is four-fifths silent has no
business taking up five letters of space.

## Run it

```sh
node main.ts
```

This writes exactly one word, `queue`, to `/output/entry.txt` — 5 bytes,
no trailing newline, nothing else attached.
